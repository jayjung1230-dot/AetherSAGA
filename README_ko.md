# Aether SAGA (에테르 사가) - journeys through endless stories

> 🌐 **[English Documentation (README.md)](./README.md)** | **현재 버전:** `Ver. 1.0` (2026. 10. 28 정식 릴리즈) | [릴리즈 노트 전문 (RELEASE_NOTES.md)](./RELEASE_NOTES.md)  
> 🏷️ **키워드 / 검색 태그:** `ebook` • `e book` • `e-book` • `e-ink` • `reader` • `viewer` • `전자책` • `리더기` • `뷰어`  
> **E-Ink 전자책 단말기 및 저사양 Android 기기를 위한 초경량·고성능 전자책/만화 뷰어**  
> *"Aether SAGA, journeys through endless stories"*

**Aether SAGA**는 크레마 루나 X(Crema Luna X, 6.0"), 오닉스 북스(Onyx Boox) 등 E-Ink 디바이스 및 안드로이드 태블릿/스마트폰 환경에서 **극도의 반응 속도, 메모리 효율성, 최적의 배터리 수명, 방해 없는 독서 공간**을 제공하기 위해 설계된 안드로이드 전자책 리더입니다.

무거운 서드파티 라이브러리(Compose, Hilt, Glide/Coil, Retrofit/OkHttp, AppCompat 등)를 완전히 배제하고, **순수 Android 프레임워크 뷰와 경량 Kotlin 코루틴, Room DB**만을 사용하여 빌드 크기를 2MB 안팎으로 억제하면서도 풍부한 독서 기능을 제공합니다.

---

## 📌 주요 특징 및 설계 철학

1. **극도의 경량화 & 최소 의존성 (Zero Heavy Library Policy)**
   - Jetpack Compose, AppCompat, Hilt, Retrofit, Glide 일체 배제
   - 순수 Android Framework View + Room DB(KSP) + Kotlin Coroutines만 사용
   - 설치 파일(APK) 크기 초경량 유지 및 즉각적인 콜드 스타트 시간 달성

2. **E-Ink 디스플레이 완벽 대응 & 핵심 4대 모드 단순화 (Display Modes & Checkmark)**
   - **자동 감지 및 4대 디스플레이 모드**: 불필요하게 복잡한 개별 해상도 프리셋 목록을 정돈하고, `자동 감지 (권장)`, `흑백 E-Ink (Carta 1300/1200)`, `컬러 E-Ink (Kaleido 3)`, `일반 LCD / OLED (컬러)` 4대 핵심 모드로 단순화
   - **체크 표시(`✓`) UI**: 현재 적용 중인 디스플레이 모드 및 테마 항목 앞에 즉각적인 체크마크(`✓`)를 표출하여 선택 상태 시인성 확보
   - **E-Ink 가독성 극대화**: 전자잉크 단말에서는 소프트웨어 컬러 필터나 세피아 틴트를 완전 차단하여 순수 종이/잉크 대비를 보호하며, 고스트 방지 전체 화면 리프레시(1~30페이지) 주기 지원
   - **텍스트 굵기(Boldness)**: 0~10단계 하드웨어 렌더링 증폭 및 프론트라이트 밝기/색온도 듀얼 제어

3. **기기 환경 맞춤형 하드웨어 기능 은닉 & 이원화 UX (Bifurcation Architecture)**
   - **E-Ink 단말**: 
     - 소프트웨어 컬러 테마 및 눈 보호 필터 완전 은닉 (Carta 반사형 패널 특성에 맞게 순수 Paper/Ink 고정)
     - 바이오닉 리딩(Bionic Reading) 영구 삭제 (특허 및 상표권 리스크 0% 달성)
     - 완전한 플리커 프리 인스턴트 페이지 전환 고정, 외부 오디오(BT/이어폰) 전용 안전 TTS
   - **LCD/OLED 단말**:
     - **독서 화면 테마 (Eye-Care & Night)** 탑재:
       - 📄 기본 화이트 (Natural Paper: `#FBFBF8` / `#111111`)
       - 📜 눈 보호 웜톤 / 세피아 (Blue Light Filter & Warm Amber: `#F5EEDB` / `#2C2216`)
       - 🌙 야간 독서 다크모드 (Night Charcoal: `#141416` / `#EEEEEE`)
       - ⚫ OLED 트루 블랙 (True Black: `#000000` / `#D0D0D0`)
     - E-Ink 전용 잔상 제거(Full Refresh) 주기 설정 UI 완전 은닉

4. **다양한 도서 및 만화 포맷 지원**
   - **텍스트/문서**: EPUB, TXT, PDF, MOBI, AZW3, Markdown(MD)
   - **만화/코믹스**: CBZ, CBR, ZIP (자동 양면 분할, 우→좌/좌→우 방향, E-Ink 콘트라스트 부스트)

5. **오프라인 중심 & 자체 무선 동기화**
   - 기기 내 독립형 경량 HTTP 서버 탑재 (Wi-Fi를 통한 PC/스마트폰 무선 책 전송)
   - WebDAV 원격 백업 및 마크다운 하이라이트 동기화
   - 전체 데이터/설정 원클릭 백업 및 복원 (JSON/ZIP 내보내기/가져오기)

## 🚀 현재 구현된 기능 목록 (Features)

### 1. 뷰어 및 타이포그래피 (Viewer & Typography)
- **정밀한 텍스트 렌더링 & 고급 타이포그래피**:
  - 폰트 크기(pt), 줄간격(Line Height, 1.0x~3.0x), 문단 간격(dp), 자간(letter-spacing), 좌우 여백(Margin dp) 조절
  - **가변 폰트 웨이트 세부 조절 (Variable Font OpenType 'wght')**: 100~900 범위의 미세 굵기 조절 지원
  - **E-Ink 전용 엣지 스트로크 부스터 (Edge Stroke Booster)**: Carta 1300/1200 패널 가독성을 위한 외곽선 증폭(0~10단계)
  - 하단 푸터 폰트 크기(좌측 챕터 제목, 우측 독서 진행률) 가독성 최적화(11.5pt)
  - 원본 문서 스타일 우선 / 사용자 커스텀 스타일 전환 토글
  - 커스텀 폰트(TTF/OTF) 동적 로딩 및 적용 (`Fonts/` 디렉토리 연동)
- **목차(TOC) UX 및 메타데이터 헤더**:
  - 책 제목 굵은 글씨 및 상세 정보(작가, 옮긴이, 출판사, 출시 연도) 상단 헤더 표시
  - **뒤로가기 버튼과 책 정보의 세로 분리 배치**: 상단에 뒤로가기 버튼을 배치하고 그 아래로 도서 메타데이터를 위치시켜 터치 오작동 방지 및 레이아웃 통일성 확보
  - **E-Ink 기기 전용 목차 구분선 이원화 및 18dp 여백**: e-INK 단말 환경에서 도서 메타정보 아래 구분선은 양쪽 여백(18dp)이 있는 깔끔한 **직선**으로, 각 챕터들 사이의 구분선은 양쪽 여백(18dp)이 있는 **옅은 점선**(`DashPathEffect`)으로 차별화하여 계층 구조의 시각적 명확성과 e-ink 가독성을 극대화 (LCD/OLED는 단색 실선 유지)
  - 우측 영구 스크롤바 인디케이터 지원
  - 창닫기 '✕' 버튼 제공
  - 챕터 순서 앞 은은한 페이지 번호 표시 (`12p  제1장`)
  - 무의미한 가짜 챕터(`Chapter 1`, `Section 1` 등) 자동 필터링 및 실제 목차만 선별 표출
  - **상시 노출 고대비 수직 스크롤바 (`EinkScrollBarView`)**: 목차(TOC) 및 설정 창(조판, 화면/회전, 보조도구, 환경설정 등) 스크롤이 필요한 모든 창에 E-Ink 특화 전용 7dp 커스텀 스크롤바 뷰 탑재. 안드로이드 프레임워크나 롬 테마의 스크롤바 비활성화 버그에 영향을 받지 않고 고대비 차콜(#222222) 썸과 웜그레이(#E4DFD7) 트랙이 즉시 선명하게 표시되며, 터치 드래그 패스트 스크롤 지원
- **인라인 각주 팝업 인터랙션 (Inline Footnote Resolver)**:
  - 본문 이탈 없이 즉시 각주/노트 내용을 확인하는 오버레이
  - **E-Ink 모드**: 플리커 방지 및 가독성을 위한 2dp 고대비 실선 테두리 + 인스턴트 노애니메이션 카드 + 명확한 '✕' 닫기 버튼
  - **LCD/OLED 모드**: 반투명 딤(Dim) 백드롭 + 라운드 코너 바텀시트 + 제스처 드래그 핸들 바
- **인코딩 자동 감지**: TXT 파일의 UTF-8, CP949(x-windows-949), EUC-KR, Shift_JIS 인코딩 감지 및 수동 변경
- **드롭캡 (Drop Caps)**: 챕터 시작 첫 단어 확대 강조 스타일 지원
- **독서 집중 및 보조 도구**:
  - **독서 룰러 (Reading Ruler)**: 현재 읽고 있는 줄에 포커스를 유지하는 가이드 오버레이
  - **뽀모도로 타이머 (Pomodoro Timer)**: 25분 집중 / 5분 휴식 독서 타이머
  - **독서 페이스 기반 완독 예상 시간 계산기 & 스크러버 2줄 분리 (Time-to-Finish Estimator & 2-Line Scrubber)**:
    - 실시간 읽기 속도를 지수 평활법으로 계산하여 챕터 및 도서 전체 완독까지 남은 시간을 상태바 및 스크러버에 직관적으로 표시
    - **스크러버 2줄 표시**: 독서 중 화면 중앙을 눌러 호출하는 하단 진행 창(`scrubberLabel`)을 2줄로 분리하여 가독성을 극대화 (1행: 전체 페이지 정보 및 진행률 `전체 N / Total 페이지 • P%`, 2행: 완독까지 남은 예상 시간 `완독까지 M분`)
  - **핸즈프리 자동 책넘김 (Hands-Free Auto Page Turn)**: 10초~120초 간격으로 터치 없이 자동 페이지 전환, 수동 터치 시 지능적 타이머 리셋 및 완독 시 자동 종료
  - **하단 푸터 폰트 가독성 최적화 (+1PT 확대)**: 독서 화면 최하단 좌측 챕터 정보 및 우측 독서 진행률 폰트 크기를 1PT 확대하여 E-Ink 및 소형 단말기에서의 시인성 향상
  - **인라인 하이라이트 독서 메모 & 입력 시간 정밀 분리**:
    - 본문 하이라이트 영역 터치 시 `[ ✎ 메모 ] | [ ✕ 삭제 ]` (LCD/OLED 기기에서는 `[ 📱 SNS ]` 포함) 팝오버를 띄워 즉각적인 메모 등록/수정/삭제 지원
    - **입력 시간 분리**: 850ms 미만 터치는 3x3 터치존 명령으로 즉각 실행되며, 850ms 이상 누르고 있을 때만 하이라이트 드래그 선택 모드가 활성화되어 터치 오동작 원천 방지
    - **PDF 하이라이트 잔상(Ghosting) 완전 차단**: 뷰 레이어 오버레이 즉시 리셋, 비트맵 스테이징 버퍼 소거, E-Ink 하드웨어 풀 리프레시 연동의 3중 방지 아키텍처 적용
  - **도서 삭제 시 하이라이트 영구 보관 (Book Metadata Decoupling & Yes/No 옵션)**:
    - 책장에서 도서를 삭제할 때 `[하이라이트 보관 및 책 제거] (Yes)` vs `[하이라이트도 함께 삭제] (No)` 선택 옵션 제공
    - 원본 도서 파일이나 책장 목록에서 책이 제거되더라도 도서명/저자 정보와 함께 하이라이트와 독서 메모가 영구 보존됨
  - **하이라이트 압축파일(ZIP) 및 독서 노트 SNS 확장 공유 (Email & SNS Note Sharing)**:
    - 도서별 또는 보관된 전체 하이라이트를 표준 텍스트(.txt) 및 마크다운(.md)으로 묶어 ZIP 압축 파일 자동 생성
    - 단일화된 직관적 전송 버튼 및 전송 창 최상단 도서 메타데이터(제목, 저자) 친절 안내
    - 안드로이드 표준 `FileProvider` 및 `Intent.ACTION_SEND` (application/zip)를 통해 기기 내 이메일 앱으로 다이렉트 전송
    - **이메일 및 SNS 독서 카드 통합 연동**: 독서 노트 공유 다이얼로그 및 도서 내보내기 메뉴에서 이메일 전송과 함께 Instagram, Threads, X, Facebook 등 주요 SNS로의 감성 독서 카드 공유 버튼을 원클릭 제공
  - **SNS 독서 카드 공유, 카카오톡, 문자 메시지(SMS) 및 갤러리 이미지 저장 (Zero-SDK & Scoped Storage)**:
    - **독서 카드 이미지 저장 (Save to Gallery)**: E-Ink 및 LCD/OLED 모든 기기에서 1080×1080 고해상도 독서 카드를 기기 사진 보관함(`Pictures/AetherSAGA`)에 원클릭으로 안전 저장 (Android 10+ Scoped Storage 연동, 런타임 저장소 권한 요구 제로)
    - **카카오톡(KakaoTalk) 지원 (LCD/OLED)**: 공식 브랜드 옐로우/브라운 테마 아이콘, 카카오톡 앱으로 독서 카드 이미지 및 인용구 즉시 전송 (미설치 시 구글 플레이스토어로 자동 안내, E-Ink 기기에서는 원천 은닉)
    - **문자 메시지(SMS/MMS) 연동**: 통신/SMS 기능이 탑재된 스마트폰/태블릿(`FEATURE_TELEPHONY`)에서 기본 문자 앱으로 카드 이미지와 텍스트를 자동 첨부하여 전송 (문자 기능이 없는 E-Ink 기기에서는 완벽 은닉)
    - **글로벌 SNS 지원 (전 기기 공통)**: Instagram, Threads, X(구 Twitter), Facebook 4대 SNS 다이렉트 전송 및 스토어 라우팅 (E-Ink 및 LCD/OLED 공통 지원)
    - **기기 맞춤형 하드웨어 이원화**: 카카오톡 및 문자 메시지는 LCD/OLED 및 셀룰러 지원 기기 전용으로 동작하며 E-Ink 기기에서는 원천 은닉하여 최적화
  - **E-Ink 고대비 설정 UI 보강 & 옅은 점선 구분선 (환경설정 & 리더 설정·도구)**:
    - Carta 1300/1200의 16단계 그레이스케일 패널에 맞추어 메뉴 묶음 카드에 따뜻한 연회색 배경(`ReaderTheme.EINK_CARD_BG`)과 2px 차콜 테두리(`ReaderTheme.EINK_BORDER_CONTRAST`)를 적용
    - 카드 내부의 모든 버튼과 아이콘에 화이트 필 배경과 2px 고대비 외곽선을 부여하여 시각적 경계선("바탕선") 선명화
    - **메뉴 항목 간 가로 구분선 옅은 점선(`DottedDividerView`) 적용**: 글자 스타일(현재 글꼴과 사용자 폰트 추가 사이 등), 화면/조명, 독서 보조도구, 환경설정의 모든 카드 내부 구분선을 부드러운 옅은 점선(`0xFF888888`, 3dp 대시/3dp 갭)으로 전환하여 직선의 답답함을 해소하고 시각적 계층감 완성
    - 보조 도구 설정 메뉴에서 플래시카드 복습, 독서 통계 대시보드를 전용 배경 박스(`extraCard`) 내부에 그룹화하여 직관적인 조작 제공
  - **일일 독서 통계 트래커 & 주간/월간/연간 대시보드**:
    - 오늘 읽은 시간(분)과 페이지 수를 측정하여 서재 헤더에 표출
    - **주간(최근 7일) · 월간(최근 4주) · 연간(12개월)** 기간 비교 지원
    - **주간 읽은 도서 목록 및 진도율 표출**: 최근 7일 내 읽은 도서 목록을 대시보드에 표출하며, 읽던 중인 도서는 `(읽고 있는 페이지) / (전체 페이지)`, 완독 도서는 `완독` 배지와 체크마크 표출
    - **Zero-Library 순수 Canvas 라인(Line) 차트 엔진**: MPAndroidChart 등 외부 라이브러리 없이 직접 조판한 초경량 고대비 라인 그래프 탑재 (E-Ink 3px 고대비 실선/도트, LCD 부드러운 스플라인/그라데이션)
    - 독서 시간(분) ↔ 읽은 페이지(p) 지표 전환 및 연속 독서일(Streak 🔥) 집계
    - **월별/연간 완독 도서 기록 영구 보존**: 도서 파일 삭제 후에도 월별 완독 권수와 완독 도서 목록 영구 보존
    - **독서 통계 SNS 공유 및 이미지 저장 (전 기기 지원)**: 독서 시간, 완독 권수, 연속 독서일 요약 카드 저장 및 SNS 공유 지원 (E-Ink 기기는 갤러리 저장 및 주요 글로벌 SNS, 카카오톡/문자는 은닉)
- **TTS (음성 읽기, H/W 맞춤형 오디오 라우팅)**:
  - **LCD/OLED 태블릿**: 기기 내장 스피커를 통한 직접 음성 낭독 지원
  - **E-Ink 단말**: 도서관이나 조용한 독서 환경에서의 돌발 소음을 방지하기 위해 블루투스 오디오 또는 유선 이어폰 연결 시에만 활성화
- **순수 즉시 전환 (Zero Animation Instant Transition)**:
  - 플리커 및 잔상(Ghosting)을 유발하는 무거운 3D 책장 넘김 효과를 완전히 배제하고, E-Ink 패널 및 저전력 환경에 최적화된 즉각적인 래스터 전환 적용
- **6인치 화면 맞춤형 통합 다이얼로그 규격 (`showWithOptimalWidth`)**:
  - 설정, 조판, 화면/회전, 보조도구 창이 모두 동일한 규격(2dp 고대비 테두리 박스) 안에서 쾌적하게 렌더링
  - **은은한 배경 딤(0.35f) 및 카드 드롭 섀도우**: 모달 뒤 화면을 자연스럽게 가라앉히는 은은한 딤과 입체감 복구
  - **2단 계층 헤더 내비게이션**: 상단 1열에 `◀ 뒤로` 버튼과 `✕` 닫기 버튼, 하단 2열에 메뉴 제목을 분리 배치하여 조작성과 시인성 극대화
  - **상시 고대비 수직 스크롤바**: 서재 메인 GridView 및 모든 팝업 스크롤 영역에 비페이딩 고대비 스크롤바 탑재로 현재 위치 인지 보장
- **내비게이션 히스토리**: 목차(TOC)나 각주 등으로 페이지 이동 시 이전 읽던 위치로 돌아갈 수 있는 뒤로가기 스택 지원

### 2. E-Ink 특화 & 하드웨어 제어 (Hardware & E-Ink)
- **디스플레이 프로필 감지**:
  - `MonoEInkStrategy`: 흑백 E-Ink 단말(Carta 등) 최적화 (ALPHA_8 고속 렌더링, 인스턴트 전환)
  - `ColorEInkStrategy`: 컬러 E-Ink(Kaleido 등)에 맞춘 리프레시 및 팔레트 처리
  - `LcdOledStrategy`: 일반 태블릿을 위한 부드러운 슬라이드 및 3D 책장 넘김 전환
- **하드웨어 키 리매핑**:
  - 볼륨 업/다운 키, 블루투스 리모컨, 페이지 넘김 물리 키 커스텀
  - **짧게 누름 / 길게 누름** 분리 매핑 (이전 페이지, 다음 페이지, 전체 새로고침, 책갈피, 메뉴, 다크모드)
- **3x3 터치 존 (Touch Zones)**: 화면을 9개 영역으로 나누어 각 터치 구역별 액션 사용자 지정
- **프론트라이트 컨트롤**: E-Ink 기기의 CTM(Color Temperature Management) 브로드캐스트 및 밝기/색온도 제어
- **보조 플로팅 내비게이션 (`NavAssistService`, `FloatingNavManager`)**: 안드로이드 SAF 시스템 파일 선택기 등에서 물리 백버튼이 없는 기기를 위한 플로팅 뒤로가기/닫기 오버레이 버튼 제공

### 3. 만화 / 코믹스 뷰어 (Comic & Manga Engine)
- **ZIP, CBZ, CBR 스트리밍 압축 해제**: 전체 압축을 풀지 않고 필요한 페이지만 메모리 스트리밍으로 즉시 디코딩
- **스마트 분할 (Page Splitter)**:
  - 양면 스캔된 와이드 이미지를 좌/우 페이지로 자동 분할
  - 뷰 모드 지원: `AUTO_SPLIT`, `FIT_WIDTH` (너비 맞춤), `FIT_HEIGHT` (높이 맞춤), `SPREAD_PAIR` (양면 펼침)
- **읽기 방향 전환**:
  - `LTR` (좌 → 우: 일반 서양식/한국 만화)
  - `RTL` (우 → 좌: 일본 만화 전통 방식)
  - `VERTICAL` (위 → 아래: 웹툰 스크롤 방식)
- **E-Ink 만화 콘트라스트 부스트 (Contrast Boost)**: 흑백 화면에서 흐릿한 톤과 연필 선화를 뚜렷하게 보정하는 감마/대비 증폭
- **메모리 절약형 디코더 (Subsampled Bitmap Decoder)**: OOM(Out of Memory) 방지를 위해 뷰포트 크기에 맞추어 `inSampleSize` 최적화

### 4. 서재 및 파일 관리 (Library & Files)
- **책장(Bookshelf) 브랜딩 & 커스텀 분류**:
  - 최초 책장 화면 좌측 상단 공식 브랜드 로고: **Aether SAGA**, *journeys through endless stories*
  - 사용자 맞춤형 책장 생성, 이름 수정, 삭제 기능
  - 책장별 필터링 드롭다운 메뉴 (`📚 책장: 전체 ▾`)
  - 단일 도서 롱클릭 메뉴를 통한 책장 이동 및 다중 선택 모드(`선택 모드`)를 통한 일괄 책장 이동(`책장 이동 (N권)`)
  - 서재 그리드 카드에 현재 소속된 책장 배지(Badge) 표시
- **오프닝 스플래시 및 앱 아이콘**:
  - 레트로 E-Reader 픽셀 아트 감성의 웰컴 스플래시 화면 (`SplashActivity`)
  - 커스텀 런처 아이콘(`ic_launcher`)
- **다양한 탐색 방식**:
  - 기기 내부 저장소 및 SD 카드 특정 폴더 스캔
  - 안드로이드 SAF(Storage Access Framework) 단일 문서 및 폴더 피커 지원
  - 최근 읽은 책, 제목순, 작가순 정렬 필터
- **경량 썸네일 캐시 (`CoverCache`)**: 표지 이미지를 그레이스케일 WebP 포맷으로 압축 저장하여 용량과 메모리 최소화
- **진행률 저장**: 책별 마지막 읽은 시간, 챕터, 글자 오프셋, 백분율 진행도 자동 기록

### 5. 무선 전송, 백업 및 다기기 동기화 (Sync & Whispersync)
- **Whispersync 스타일 다기기 독서 위치 실시간 동기화 (E-Ink vs. LCD/OLED 이원화)**:
  - WebDAV 클라우드를 통한 챕터, 글자 오프셋, 진행률 자동 큐잉 및 동기화
  - **E-Ink 단말**: 깜빡임(Flicker) 방지 및 잔상 최소화를 위한 고대비 인스턴트 모달 대화상자 (`showWithOptimalWidth`, 애니메이션 완전 제거)
  - **LCD/OLED 단말**: 상단 플로팅 알림 스낵바 카드 (부드러운 Slide-in 애니메이션, 8초 자동 숨김 타이머, 원클릭 이어읽기 점프 버튼)
- **웹 리모트 서버 (Web Remote Server)**:
  - 기기에서 활성화 시 로컬 IP (예: `http://192.168.0.x:8080`)의 웹 인터페이스 오픈
  - 케이블 없이 PC/모바일 브라우저에서 드래그 앤 드롭으로 책 업로드 및 서재 관리
- **백업 및 복원 (Backup & Restore)**: 독서 기록, 책갈피, 하이라이트, 사용자 설정 전체를 단일 백업 파일로 내보내기/가져오기
- **WebDAV 동기화 및 친화적 가이드**:
  - 독서 노트와 하이라이트를 WebDAV 클라우드 서버에 자동 큐잉 및 동기화
  - 단순 URL 입력창을 넘어, 개인 클라우드를 통한 다기기 동기화 목적과 100% 개인정보 보호 장점을 한눈에 알기 쉽게 설명하는 안내 다이얼로그 탑재
- **하이라이트 내보내기 & 공유**:
  - 발췌문과 노트를 Markdown 포맷으로 변환
  - 안드로이드 표준 공유 시트 및 SMTP 이메일 발송 지원
  - 전체 하이라이트 묶음 ZIP 압축 파일 생성 및 원클릭 이메일 전송 지원
  - LCD/OLED 스마트폰/태블릿 기기 전용 감성 독서 카드(Instagram, Threads, X, Facebook) 공유 지원

### 6. 다국어 지원 (Bilingual Localization: 한국어 & English)
- **한국어 & 영어 2대 언어 전용 완전 지원 (Full UI Localization)**:
  - **최초 실행 시 시스템 로케일 자동 감지**:
    - 기기 시스템 언어가 한국어(`ko`)인 경우 한국어로 기본 시작.
    - 한국어가 아닌 다른 모든 언어(영어, 일본어, 중국어, 유럽어 등)인 경우 기본 언어를 영어(`en`)로 자동 확정하여 글로벌 사용자 친화적 환경 제공.
  - **설정 메뉴 내 직관적 언어 선택 및 영속화**:
    - 환경 설정 최상단에 언어 선택 카드 제공 (오직 `한국어 (Korean)` 및 `English (영어)` 2가지 선택지 지원).
    - 언어 변경 시 `SharedPreferences`에 영구 보존되어 다음 앱 실행에서도 지속 적용.
    - **전면적인 영문화 적용**: 설정창뿐만 아니라 메인 서재(책장 드롭다운 `📚 Shelf: All`, 검색 `🔍 Search`, 일괄 삭제/책장 관리 모달, 하단 하드웨어 티어 문구), 뷰어 메뉴, 목차, 독서 통계 리포트(헤더, 기간 탭, 요약 메트릭, 날짜 서식 `MMM d, yyyy`, 완독 도서 섹션), 이메일 공유 메타정보/본문, SNS 카드 생성 텍스트, 북마크 알림 토스트까지 전 영역에 걸쳐 완전한 영문화 적용.
  - **Zero-Dependency 초경량 L10n 엔진 (`L10n.kt`)**:
    - 외부 무거운 다국어 프레임워크 없이 순수 인라인 헬퍼로 구동되어 0KB 메모리 오버헤드 달성.

## ⚙️ 빌드 및 설치 방법 (Build & Setup)

### 개발 환경 요구 사항
- Android Studio Ladybug (2024.2.1) 이상 또는 JDK 17
- Android SDK (API Level 34, Build Tools 34.0.0)

### 1. 패키지 산출물 (`dist/`)
프로젝트 빌드 결과물은 `dist/` 폴더에 즉시 설치 가능한 APK로 준비되어 있습니다:
- **`dist/AetherSAGA.apk`**: 최신 릴리스 패키지 (약 555KB, R8 최적화 완료)
- **`dist/AetherSAGA-release.apk`**: R8 풀 모드 최적화 릴리스 패키지
- **`dist/AetherSAGA-debug.apk`**: 개발 및 디버깅용 패키지

### 2. 빌드 실행 명령어
- **디버그 APK 빌드:**
  ```bash
  gradle.bat assembleDebug
  ```
  결과물: `app/build/outputs/apk/debug/AetherSAGA-debug.apk`

- **릴리즈 APK 빌드:**
  ```bash
  gradle.bat assembleRelease
  ```
  결과물: `app/build/outputs/apk/release/AetherSAGA-release.apk`

### 3. 기기 설치 (ADB)
```bash
adb install -r dist/AetherSAGA.apk
```
> [!NOTE]
> Android 11(API 30) 이상 기기(예: Crema Luna X)에서는 모든 도서 파일 접근을 위해 **모든 파일 관리 권한(MANAGE_EXTERNAL_STORAGE)** 허용이 필요합니다.
